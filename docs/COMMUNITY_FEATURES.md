# Historical community feature notes

This file preserves a snapshot of feature ideas inherited from the Mylar3
community issue tracker. It is historical context, not a current Comicarr
implementation plan or architecture reference.

Comicarr's supported architecture is the FastAPI domain structure described in
`AGENTS.md` and the project README. New work should be scoped there and should
not target retired CherryPy, Mako, or flat root-level Mylar3 modules.
