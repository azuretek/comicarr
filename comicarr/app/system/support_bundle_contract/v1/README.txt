Comicarr Support bundle
Contract version 1

This archive is intended for Comicarr maintainers helping troubleshoot Comicarr.
It contains only allowlisted diagnostic facts. It is not a copy of your database
or settings file and does not include settings values, raw log lines, library
names, paths, chat content, or other free text. It may include normalized
configuration states and bounded aggregate count buckets.

Before sharing
1. Review README.txt, manifest.json, and diagnostics.json.
2. Attach this archive to a public issue only if you are comfortable with every value.
3. If anything appears sensitive, share it privately with a maintainer instead.

manifest.json describes the contract, archive members, and source availability.
diagnostics.json contains the versioned diagnostic projection.

Operator review is required. This archive is engineered for public issue attachment
after review; it is not a guarantee that every value is appropriate to share.
